Launcher Plugins

Extend the Launcher with your own integrations. A plugin is just a standalone script — no SDK, no build step, no compiling.

How it works

Tabame runs your script (Python, Node.js or Bun) as a small background process and talks to it over stdin/stdout with newline-delimited JSON.

Drop-in Install

Drop a plugin folder into %localappdata%\Tabame\plugins\<id>\ and reopen the Launcher — it rescans on every open, no restart needed.

Keyword Activation

Type the plugin's keyword to activate it, then keep typing to query it live.

Simple Protocol

Tabame sends JSON events (init, query, select, action, close) on stdin; your script answers with render frames on stdout. That's the entire contract.

Build one with AI

The whole protocol is written down as a spec an AI coding assistant can read and follow — describe what you want and let it scaffold the plugin for you.

Authoritative Spec

plugins/TABAME_PLUGIN_SKILL.md in the repo documents every message type, render-frame field, view type and icon name, plus a plugin.json template.

Working Examples

Copy the shape of plugins/echo, plugins/linear and plugins/caniuse — list/grid/detail views, external APIs, secrets from config.json.
